## 5. 🟠 Проверка обязательных выходных слотов и совместимости жидкостей — исправлено в коде, требуется проверка

Файл: `CN_MiningMachines_Server/Scripts/4_World/CN_OilDistiller_Server.c`

**Согласованное поведение:**
- Для запуска обязательны оба выходных слота: `RecycleOutput` и `RecycleRare`.
- Контейнер в каждом слоте должен быть совместим с жидкостью, заданной соответственно в `OutputClass` и `RareClass`.
- Пустой совместимый контейнер допустим; контейнер с уже налитой несовместимой жидкостью — нет.
- Если один из обязательных выходов отсутствует, заполнен или несовместим, запуск запрещён.
- Во время работы доступность и совместимость обоих выходов проверяется повторно перед циклом.
- Основной и редкий продукты направляются только в предназначенные им слоты. Перенаправление редкой фракции в основной слот удалено.
- Если целевой выход стал недоступен, процесс останавливается до списания сырья за текущий цикл.

**План проверок на сервере:**
1. Оба выходных контейнера пустые и совместимые — дистиллятор запускается.
2. В `RecycleOutput` находится вода, а основной продукт — бензин — запуск запрещён.
3. В `RecycleRare` находится несовместимая жидкость — запуск запрещён.
4. Один из выходных слотов пуст (контейнер не установлен) — запуск запрещён.
5. Один из контейнеров заполнен — запуск запрещён.
6. Во время работы один из выходных контейнеров удалён, заполнен или стал несовместимым — процесс останавливается, сырьё за невыполненный цикл не списывается.
7. При доступности обоих выходов основной продукт попадает только в `RecycleOutput`, редкая фракция — только в `RecycleRare`; резервного перенаправления нет.
8. Проверить компиляцию мода и отсутствие ошибок в серверном логе.

**Статус:** код обновлён; серверные проверки не выполнены. Пункт не закрывать до проверки всех сценариев.
 
## 6. 🟠 Проверка свободного объёма выходной тары — исправлено в коде, требуется проверка

Файл: `CN_MiningMachines_Server/Scripts/4_World/CN_OilDistiller_Server.c`

**Согласованное поведение:**
- Для успешного цикла целевой выходной контейнер должен иметь свободное место не меньше полного `LiquidOutVolumePerTick`.
- Пропорциональное уменьшение расхода сырья при недостатке места удалено.
- Если свободного места недостаточно, дистиллятор останавливается: продукт не добавляется, сырьё за невыполненный цикл не списывается.
- Если выходной контейнер заполнен, дистиллятор останавливается без списания сырья.
- Если `LiquidOutVolumePerTick` или `LiquidBurnVolumePerTick` равно нулю или меньше нуля, цикл не выполняется, дистиллятор останавливается.
- При достаточном свободном объёме продукт добавляется штатным объёмом, после чего списывается соответствующее количество сырья.

**План проверок на сервере:**
1. Свободного места достаточно для полного объёма продукта — цикл выполняется штатно.
2. Контейнер частично заполнен, но свободного места меньше `LiquidOutVolumePerTick` — дистиллятор останавливается, продукт и сырьё не изменяются.
3. Контейнер заполнен — дистиллятор останавливается без списания сырья.
4. Проверить нулевые и отрицательные значения `LiquidOutVolumePerTick` и `LiquidBurnVolumePerTick`.
5. Проверить компиляцию мода и отсутствие ошибок в серверном логе.

**Статус:** код обновлён; серверные проверки не выполнены. Пункт не закрывать до проверки всех сценариев.
## 7. 🟠 Граничные случаи жидких и твёрдых отходов — исправлено в коде, требуется проверка

Файл: `CN_MiningMachines_Server/Scripts/4_World/CN_OilDistiller_Server.c`

**Согласованное поведение:**
- Жидкие отходы начисляются только при наличии места для полного `LiquidWasteVolumePerTick`. Если полного объёма не помещается, станок останавливается без добавления отходов и без списания сырья.
- Твёрдые отходы ищутся по всему инвентарю станка, а не только в слоте `RecycleWaste`.
- Если твёрдый отход найден, проверяется класс и наличие места для полного `WasteAmountPerTick`; если не найден — предмет создаётся в инвентаре станка.
- Если твёрдый отход нельзя создать или увеличить на полный настроенный объём, цикл останавливается без списания сырья.
- Перед выбором результата проверяются конфигурация, допустимость вероятностей и объёмов, наличие полного объёма сырья для цикла и совместимость обязательных выходных контейнеров.
- Если сырья меньше `LiquidBurnVolumePerTick`, остаток не перерабатывается: станок останавливается без начисления результата и без списания сырья.
- За цикл выбирается один результат. Сначала результат начисляется и проверяется, затем исходное сырьё списывается ровно один раз.
- При неудачном начислении результата сырьё не списывается.

**План проверок на сервере:**
1. Жидкий отход: места достаточно для полного объёма — цикл начисляет отход и списывает сырьё один раз.
2. Жидкий отход: свободного места меньше `LiquidWasteVolumePerTick` — станок останавливается, содержимое отходной тары и сырьё не изменяются.
3. Твёрдый отход уже находится в cargo или другом месте инвентаря станка, вне `RecycleWaste` — количество увеличивается на `WasteAmountPerTick`.
4. Твёрдого отхода нет — предмет создаётся в инвентаре станка и получает настроенное количество.
5. Для твёрдого отхода нет места либо предмет нельзя создать — станок останавливается без списания сырья.
6. В сырьевой таре ровно `LiquidBurnVolumePerTick` — выполняется один полный цикл.
7. В сырьевой таре меньше `LiquidBurnVolumePerTick` — остаток не перерабатывается, результат не начисляется.
8. Проверить нулевые/отрицательные объёмы, некорректные вероятности, компиляцию и серверный лог.

**Статус:** код обновлён; компиляция и серверные проверки не выполнены. Пункт не закрывать до проверки сценариев.

## 9. 🟠 Проверка питания и остановки — исправлено в коде, требуется проверка

Файл: `CN_MiningMachines_Server/Scripts/4_World/CN_OilDistiller_Server.c`

**Согласованное поведение:**
- Проверка фактической работы энергосистемы соответствует насосу: `!GetCompEM() || !GetCompEM().IsWorking()`.
- При потере питания во время работы дистиллятор останавливает таймер, выключает питание и не продолжает цикл.
- При удалении входной тары, недостатке сырья или проблемах с выходными контейнерами процесс останавливается без списания сырья за невыполненный цикл.
- Автоматический перезапуск не нужен. После любой остановки пользователь должен вручную запустить дистиллятор через экшен; восстановление питания или замена тары сами по себе не должны запускать его.

**План проверок на сервере:**
1. Во время работы отключить питание/кабель или выключить генератор — дистиллятор останавливается и не списывает сырьё за незавершённый цикл.
2. Удалить входную тару или оставить меньше `LiquidBurnVolumePerTick` — дистиллятор останавливается без начисления продукта и списания сырья.
3. Во время работы удалить, заполнить или заменить целевой выходной контейнер — процесс останавливается без списания сырья за невыполненный цикл.
4. Восстановить питание и условия — дистиллятор не стартует автоматически; ручной экшен запускает его штатно.
5. Проверить компиляцию мода и серверный лог.

**Статус:** проверка питания обновлена в коде; компиляция и игровые проверки не выполнены. Пункт не закрывать до тестирования.
